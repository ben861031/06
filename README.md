# 印鑑借用管理系統 v15.3 手機版頁首導覽修正版

本版以 v15.2 為基礎，專門修正手機版頁首過高、主導覽被裁切及下拉選單只能在狹小區域操作的問題。借用流程、權限、人員資料與桌機版介面均維持原有行為。

## 主要調整

- 手機頁首改為「品牌識別、登入者資訊、主要功能列」三層穩定排列。
- 公司 Logo、系統名稱、使用者與登出按鈕重新對齊，避免彼此擠壓。
- 借用作業與系統管理改為兩欄等寬功能列，不再使用水平捲動。
- 移除造成絕對定位下拉選單被裁切的 `overflow-x: auto` 行為。
- 下拉選單依左右按鈕分別靠左、靠右展開，並限制在手機視窗內。
- 系統管理項目過多時可於下拉區域垂直捲動，不會推動整頁或遮住底部內容。
- 360px、390px 使用較緊湊字級與間距，桌機版媒體查詢以外樣式未變更。

## 資料與權限

- 共用人員主檔仍使用 `members`、`memberAccounts`。
- 印鑑系統角色仍使用 `sealPermissions`。
- 本版未修改集合、欄位、登入流程或 Firestore 規則。

## 部署

### GitHub Pages

只上傳「GitHub上傳資料夾」中的：

- `index.html`
- `styles.css`
- `app.js`
- `assets/`

### Firebase

「Firebase部署設定」內的規則及索引不用放入 GitHub Pages。本版只有介面修正，若線上已部署相同規則，不需要重新部署 Firebase。

## 驗證

- `node --check app.js`。
- 390 x 844：無水平捲軸，系統管理下拉完整位於視窗內。
- 360 x 800：無水平捲軸，系統管理下拉完整位於視窗內。
- 下拉選單可點擊到「操作紀錄」。
- 桌機版 CSS 未落入本版手機媒體查詢，原版型不受影響。

詳細結果請參閱 `v15.3_更新與驗證報告.md`。
