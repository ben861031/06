# 印鑑借用管理系統 v15.24 操作紀錄欄位對齊版

操作紀錄詳情以相同順序顯示異動前後的欄位，缺少的值以「-」表示。桌機的相同欄位在同一列，手機依序顯示兩張卡片。

在「借用紀錄」找到借出中的紀錄，點選「編輯」即可修正實際借用時間。操作紀錄會保留修改前後的時間。詳見 `v15.23_更新與驗證報告.md`。

## v15.22 調整

- 操作者第一行顯示姓名與小型角色標籤，不再使用整欄寬度的角色色塊。
- 第二行顯示「部門 · Email」，長 Email 以省略號呈現，滑鼠移入仍可查看完整內容。
- 操作者內容維持靠左，表格儲存格保留標準 `table-cell` 排列。
- 搜尋仍可使用操作者姓名與 Email，詳情視窗保留完整資料。

- 待借出、借用中、今日應還與已逾期維持原有淡黃色、淡藍色、淡紫色及淡紅色。
- 已歸還改為低彩度淡青綠底、青綠邊框與深青綠文字，狀態篩選及詳情徽章同步調整。
- 月份標題改為深灰黑，星期與本月日期改為中性深灰，非本月日期維持淡灰。
- 今天日期數字仍使用深藍，系統標題、按鈕及其他頁面不變。

- 星期欄位由「週日～週六」改為「星期日～星期六」，並明確維持星期日為第一欄。
- 月曆日期由「1日、2日」精簡為「1、2」。
- 今天取消日期實心圓圈，改為整個日期格淡藍底，日期數字以深藍粗體標示。
- 月份標題大小、月／週／清單切換、狀態篩選與既有行事曆功能維持不變。

- 移除借用登記右上角「可借用／借出」統計，保留並縮小三步驟流程。
- 行事曆詳情的狀態移至右上角、靠近關閉按鈕，並改為低彩度語意徽章。
- 修正操作紀錄詳情視窗被頂部導覽列遮住的問題，內容區維持獨立捲動。
- 系統管理取消分類小標，改為「基礎設定、人員管理、權限管理、操作紀錄、登入紀錄」五個平面選項。
- 「基礎資料設定」改名為「基礎設定」，印鑑與部門表格新增獨立「調整順序」欄。
- 待借用操作改為「借用、編輯、刪除」文字按鈕；印鑑歸還改為「歸還」文字按鈕。
- 歸還作業的「歸還」採白底綠框並置中；借用紀錄的「編輯、刪除」由圖示改為文字外框按鈕並置中。
- 借用紀錄編輯視窗的「儲存」改為藍色主要按鈕，與其他編輯視窗一致。
- 修正基礎設定表格因操作容器套用在儲存格本身，造成單列被拆成上下兩段的排版問題。
- 借用登記三步驟流程移至標題右側空白區，桌機不再額外占用一列；手機自動排列於標題下方。
- 待借用主要操作由「轉正式借用」簡化為「借用」，與編輯、刪除按鈕更一致。
- 基礎設定的印鑑名稱與部門名稱資料值改為置中，與表頭對齊。
- 印鑑行事曆的狀態篩選移至標題右側，移除原本獨立狀態區；日期格高度同步縮減，並新增月／週／清單檢視切換。
- 待借用管理的「借用」改為藍色外框按鈕，與編輯、刪除採一致的白底外框形式。
