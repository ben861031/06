# 印鑑借用管理系統 v15.4 權限名單與導覽整理版

本版以 v15.3 為基礎，整理權限管理的欄位層級與系統管理導覽分類。借用流程、共用人員資料、印鑑角色權限與 Firestore 資料結構均維持不變。

## 本版調整

- 將「登入紀錄」歸入「系統紀錄」，與「操作紀錄」放在同一分類。
- 權限新增列的「新增／更新權限」按鈕與兩個下拉欄位對齊。
- 移除各成員角色下方重複的說明文字，保留上方角色選擇的單一說明。
- 權限名單將「成員」拆成「部門」及「姓名」，方便掃讀與比對。
- 手機版維持單欄新增表單；寬表格可橫向捲動，不壓縮操作按鈕。

## GitHub Pages 部署

只需上傳 `GitHub上傳資料夾` 內的：

- `index.html`
- `styles.css`
- `app.js`
- `assets/`

## Firebase

本版沒有修改 Firestore 規則、索引或資料結構，不需重新部署 Firebase 設定。

詳細驗證結果請參閱 `v15.4_更新與驗證報告.md`。
