# 印鑑借用管理系統 v15.5 權限欄寬與按鈕對齊修正版

本版以 v15.4 為基礎，微調權限管理表格與新增權限按鈕的視覺對齊。借用流程、共用人員資料、印鑑角色權限與 Firestore 資料結構均維持不變。

## 本版調整

- 修正「新增／更新權限」按鈕圖示與文字的垂直對齊。
- 姓名欄內容改為置中，與表頭一致。
- 重新配置部門、姓名、員工編號、角色、狀態與操作六欄比例。
- 手機版維持單欄新增表單；寬表格可橫向捲動，不壓縮操作按鈕。

## GitHub Pages 部署

只需上傳 `GitHub上傳資料夾` 內的：

- `index.html`
- `styles.css`
- `app.js`
- `assets/`

## Firebase

本版沒有修改 Firestore 規則、索引或資料結構，不需重新部署 Firebase 設定。

詳細驗證結果請參閱 `v15.5_更新與驗證報告.md`。
