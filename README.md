# 印鑑借用管理系統 v14.0 借用登記工作台版

本版將「借用登記」重構為左右工作台，保留印鑑即時狀態，同時降低首屏資訊量。

主要調整：
- 統計單位統一使用「組」。
- 左側以緊湊清單顯示可借用／借出中狀態；借出中直接顯示借用人。
- 點選可借用印鑑時，右側顯示新增借用表單。
- 點選借出中印鑑時，右側顯示唯讀借用資料；按「編輯資料」後才可修改並寫入稽核紀錄。
- 待借用案件轉正式借用時，自動帶入案件資料，但不預選印鑑，必須由使用者手動選擇可借用印鑑。
- 待借用案件只有在正式借用成功後才更新為「已借出」；取消帶入時仍維持待借用狀態。

## v13.9 選單圖示修正版

本版延續 v13.8 選單清爽版，修正下拉選單中「目前頁面」項目的圖示被全域 active 樣式套成白色，導致看起來像圖示消失的問題。

調整內容：
- 保留下拉選單子項目的圖示。
- 取消子項目常駐淺藍底。
- 滑鼠移過時才顯示淡藍 hover 效果。
- 保留上方父選單的目前群組提示。
