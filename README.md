# 印鑑借用管理系統 v15.0 共用人員管理與權限名單修正版

本版以 v14.9 為基礎，補齊與行政部活動調查系統、公司通用問卷調查系統共用的人員管理，同時保留印鑑系統自己的角色及權限範圍。

## 主要調整

- 系統管理新增「人員管理」，直接維護共用 `members` 與 `memberAccounts`。
- 提供新增、修改、啟用、停用、刪除、搜尋及狀態篩選。
- 提供人員 Excel 範本、匯入與匯出。
- 完整名單匯入會列出本次未出現的啟用同仁，由管理員自行勾選是否停用，不會自動刪除。
- 權限管理的共用人員下拉改列出全部啟用同仁。
- 已有印鑑權限者顯示「已設定印鑑權限」；缺 Google 帳號者顯示「未設定 Google 帳號」。
- Google 帳號可由 `memberAccounts` 或舊人員欄位相容讀取，避免舊資料被漏掉。
- 修改人員 Google 帳號時，會同步搬移該人的 `sealPermissions` 文件。

## 權限界線

- 共用人員主檔只負責「這個人是誰」。
- `sealPermissions` 負責「這個人在印鑑系統能做什麼」。
- 全域系統管理員可維護共用人員主檔。
- 印鑑 Admin 可管理印鑑角色，但不能因此修改三套系統共用人員主檔。
- 印鑑角色維持 `admin`、`user`、`viewer`，不與行政或通用問卷的權限混用。

## 部署

### GitHub Pages

只上傳下列前端內容：

- `index.html`
- `styles.css`
- `app.js`
- `assets/`

### Firebase

以下檔案不用放到 GitHub Pages：

- `firestore.rules`
- `Firestore規則_v15.0_完整合併版.txt`
- `firestore.indexes.json`

本版沿用目前三套系統共用的最新完整規則，沒有放寬任何集合權限。若線上已部署相同規則，不需重複部署。

## 注意事項

- 離職人員建議使用「停用」，以保留歷史借用及稽核資料。
- 永久刪除共用人員會刪除 `members`、`memberAccounts` 與該人的印鑑權限，但不會清除歷史借用紀錄。
- 權限下拉看得到但無法選取的人員，請依括號提示檢查 Google 帳號或既有印鑑權限。
