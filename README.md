# 印鑑借用管理系統 v14.9 Firestore 讀取與共用權限優化版

本版以 v14.8 為基礎，重點處理 Firestore 高讀取量與權限名單維護問題；既有借用、歸還、待借用、印鑑與部門功能均保留。

## 主要調整

- 操作紀錄、登入紀錄及已歸還紀錄改為每次最多讀取 100 筆，並提供「再載入 100 筆」。
- 首次登入只讀取尚未歸還的借用資料；已歸還資料進入借用紀錄頁時才載入。
- 登入紀錄、操作紀錄與權限名單改為進入對應頁面才讀取。
- 登入驗證改為依文件或 Email 精準查詢，不再掃描全部權限使用者。
- 權限管理改用共用 `members` 與 `memberAccounts` 選人，不再重複輸入部門、姓名與 Google 帳號。
- 新增印鑑專屬 `sealPermissions`，角色仍維持 `admin`、`user`、`viewer`，不與行政或通用問卷的功能權限混用。
- 提供「匯入舊權限」，將能對應共用人員的舊 `users` 白名單轉入 `sealPermissions`。
- Firestore 規則以三套系統最新完整合併版為基礎，只收緊印鑑系統集合權限。

## 角色

- `Admin`：印鑑系統完整操作、權限管理、登入紀錄與操作紀錄。
- `User`：借用、歸還、待借用及基礎資料操作。
- `Viewer`：僅瀏覽待借用與借用紀錄，不可異動資料。

共用人員資料只負責「這個人是誰」；`sealPermissions` 才決定「他在印鑑系統能做什麼」。

## 建議部署順序

1. 先部署本版前端，暫時保留目前線上 Firestore 規則。
2. 以系統管理員登入，進入「權限管理」按「匯入舊權限」。
3. 確認既有使用者均已出現在新版權限清單；無法對應者先到共用人員管理補齊 Google 帳號。
4. 再部署 `Firestore規則_v14.9_完整合併版.txt` 或同內容的 `firestore.rules`。
5. 重新登入，以 Admin、User、Viewer 各測一次。

## 部署檔案

- `index.html`
- `styles.css`
- `app.js`
- `assets/`
- `firestore.rules`
- `Firestore規則_v14.9_完整合併版.txt`
- `firestore.indexes.json`

`firestore.indexes.json` 沿用三套系統最新完整索引；本版新增的印鑑查詢均使用單欄索引，不需另建印鑑專屬複合索引。
