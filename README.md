# 印鑑借用管理系統 v15.6 權限姓名置中修正版

本版以 v15.5 為基礎，修正權限管理姓名欄只有表頭置中、實際姓名仍靠左的問題。借用流程、共用人員資料、印鑑角色權限與 Firestore 資料結構均維持不變。

## 本版調整

- 權限名單的姓名內容改為真正置中，與表頭一致。
- 針對姓名儲存格內層 `.identity-cell` 修正對齊，不影響其他頁面的身分資訊。
- 保留 v15.5 的按鈕圖示對齊、欄寬配置與手機版行為。

## GitHub Pages 部署

只需上傳 `GitHub上傳資料夾` 內的：

- `index.html`
- `styles.css`
- `app.js`
- `assets/`

## Firebase

本版沒有修改 Firestore 規則、索引或資料結構，不需重新部署 Firebase 設定。

詳細驗證結果請參閱 `v15.6_更新與驗證報告.md`。
